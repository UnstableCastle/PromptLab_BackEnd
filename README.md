# PromptLab - Backend API

This is the Spring Boot REST API for **PromptLab**, It serves as the backend, providing data access for the React frontend.

## 🛠️ Tech Stack
* **Java 17**
* **Spring Boot 3**
* **Spring Security & JWT**
* **Spring Data JPA / Hibernate**
* **MySQL 8.0**
* **Maven**

## 🚀 How to Run Locally

### 1. Database Setup
Ensure you have MySQL installed and running. Create a new database:
```sql
